============================================================
  K-MER 복합감정인지 프로토콜 시연 준비 가이드
============================================================

[ 구조 ]
  Jetson Thor (165.132.48.241) → TCP 9000번 → 네 PC (10.35.130.75)
  Jetson이 13-byte 패킷을 보내면, 네 PC에서 받아서 디코딩해서 보여줌


============================================================
  STEP 1. 네 PC에서 할 일
============================================================

1) receiver.py 파일을 네 PC에 복사한다.
   파일 위치: 이 파일과 같은 폴더의 receiver.py

   복사 방법 (네 PC cmd에서):
   scp jetson@165.132.48.241:/home/jetson/work/Real-Time-Driver-State-Emotion-Monitoring-System/gateway_v2/receiver.py C:\Users\Ryan\Desktop\

   비밀번호 물어보면 jetson 계정 비번 입력.

2) Windows 방화벽에서 9000번 포트를 연다.
   cmd를 관리자 권한으로 열고:
   netsh advfirewall firewall add rule name="KMER_RECV" dir=in action=allow protocol=TCP localport=9000

3) 수신기를 실행한다.
   cd C:\Users\Ryan\Desktop
   python receiver.py --port 9000

   "대기 중... 0.0.0.0:9000" 이라고 뜨면 성공.
   이 창은 끄지 말고 놔둔다.


============================================================
  STEP 2. Jetson에서 할 일 (내가 한다)
============================================================

시뮬레이션 테스트 (모델 없이, 바로 가능):
  python3 gateway_v2/demo_usb_send.py --simulate --tcp 10.35.130.75:9000

카메라 라이브 (K-FER 모델 + RealSense):
  python3 gateway_v2/demo_usb_send.py --live --tcp 10.35.130.75:9000

============================================================
  안 될 때
============================================================

- "연결 실패" → 방화벽 문제. STEP 1의 2번 다시 확인.
- python 없다고 뜸 → python3 대신 python 으로 실행.
- scp 안 됨 → receiver.py 내용을 메모장에 복붙해서 저장해도 됨.
- 포트 이미 사용 중 → --port 9001 같은 다른 번호 사용.
  (Jetson쪽도 같은 번호로 맞춰야 함)
