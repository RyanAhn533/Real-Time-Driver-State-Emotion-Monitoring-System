# 복합감정인지 USB 통신 프로토콜 v2
## 모트렉스 규격 적용 및 시연 결과

---

# 1. 개요

- 기존 자체 프로토콜(8B)을 모트렉스 제어기 규격(13B)으로 변경
- 슈퍼게이트 ↔ 모트렉스 양방향 통신 지원
- 감정 6종 + 상태 3종 표시/사운드 규격 반영
- E2E 파이프라인: 센서 → AI 모델 → 패킷 인코딩 → USB/TCP 전송

---

# 2. 패킷 구조 변경

## v1 (기존 — 8 bytes)

| Byte | 필드 | 값 |
|:----:|:----:|:--:|
| 0 | SOF | 0xAA |
| 1 | TYPE | 0x01 |
| 2 | SEQ | 0x00~FF |
| 3 | LEN | 0x02 |
| 4 | BODY[0] | 감정코드 + 상태플래그 |
| 5 | BODY[1] | 강도 + NegEmo |
| 6 | CRC8 | poly 0x07 |
| 7 | EOF | 0xFE |

## v2 (모트렉스 규격 — 13 bytes)

| Byte | 필드 | 값 |
|:----:|:----:|:--:|
| 0 | STX | 0x02 |
| 1 | VERSION | 0x01 |
| 2~3 | RESERVED | 0x0000 |
| 4 | DEST | 0x10 (모트렉스) / 0x00 (슈퍼게이트) |
| 5~7 | DATA LENGTH | 0x03 0x00 0x00 (LSB first, 값=3) |
| 8 | COMMAND | 0xF0 |
| 9 | BODY[0] | 감정코드(D7~D4) + Stress(D3) + LowAttn(D2) + Drowsy(D1) |
| 10 | BODY[1] | 감정강도(D7~D5) + 상태강도(D4~D2) |
| 11 | CHECKSUM | XOR (Byte0~Byte10) |
| 12 | ETX | 0x03 |

---

# 3. 주요 변경 사항

| 항목 | v1 | v2 |
|:----:|:--:|:--:|
| 패킷 크기 | 8 bytes | 13 bytes |
| STX / ETX | 0xAA / 0xFE | 0x02 / 0x03 |
| Checksum | CRC8 (poly 0x07) | XOR |
| 통신 방향 | 단방향 | 양방향 (DEST 필드) |
| COMMAND | 없음 | 0xF0 |
| SEQ 순번 | 있음 | 삭제 |
| neutral 감정 | Code 5 (전송) | Reserved (표시 안 함) |
| 슬픔/혐오 | 병합 (Code 3) | 분리 (슬픔=3, 혐오=5) |

# 4. Emotion Code 매핑

| Code | 감정 | K-FER Class | 표시 메시지 |
|:----:|:----:|:-----------:|:----------:|
| 0 | 공포 | anxious | 안전하게 함께 가고 있어요 |
| 1 | 놀람 | surprised | 괜찮습니다, 안정적으로 주행 중입니다 |
| 2 | 분노 | angry | 편안한 주행을 도와드릴게요 |
| 3 | 슬픔 | sad | 편안한 주행을 도와드릴게요 |
| 4 | 행복/기쁨 | happy | 안정적으로 주행 중입니다 |
| 5 | 혐오 | hurt | 차량이 안정적으로 유지하고 있습니다 |
| F | Reserved | neutral | (표시 안 함) |

# 5. 상태 플래그 및 표시

| 상태 | 비트 | 판정 기준 | 표시 메시지 |
|:----:|:----:|:---------:|:----------:|
| Stress | D3 | 고각성(>0.6) + 부정감정 | 편안한 주행을 도와드릴게요 |
| Low Attention | D2 | PERCLOS ∈ [0.2, 0.4) | 주행에 집중해 주세요 |
| Drowsy | D1 | PERCLOS ≥ 0.4 | 잠시 휴식이 필요해 보여요 |

- 팝업 5회 반복 (0.5s On / 0.5s Off)
- 팝업 표시 중 비프음 출력
- 감정/상태가 0 또는 Reserved이면 표시하지 않음

```

                   ←──(DEST=0x00, CMD=0xF0)──
```

# 8. E2E 파이프라인 구조

```
[센서 입력]
  RealSense D435 (카메라)
  RODE Wireless GO II (마이크)           ← 현재 카메라만 사용
  ADI Study Watch (PPG/EDA/Temp)

      ↓

[AI 추론] KMERInferencer
  K-FER: MobileViTv2 + AU Cross-Attention → 감정 7-class
  FaceMesh: PERCLOS → 졸음 판정
  Temporal Smoothing: Majority Vote + EMA

      ↓

[10-class 판정]
  감정 6종: 공포/놀람/분노/슬픔/행복/혐오
  상태 4종: Stress / LowAttention / Drowsy / Fatigue

      ↓

[PacketEncoder v2]
  13-byte 모트렉스 패킷 생성
  XOR Checksum

      ↓

[전송]
  USB Serial → 모트렉스 제어기 (실차)
  TCP Socket → PC 수신기 (테스트)
```

# 10. 소프트웨어 구성

```
gateway_v2/
├── packet_encoder.py     ← 13B 패킷 인코더/디코더
├── gateway_sender.py     ← USB Serial + TCP 전송기
├── e2e_pipeline.py       ← E2E: 센서→AI→패킷→전송
├── demo_usb_send.py      ← 시연 스크립트 (4가지 모드)
├── receiver.py           ← PC 수신기 (테스트용)
└── demo_pipeline.py      ← 데모 파이프라인
```

| 모드 | 명령 | 용도 |
|:----:|:----:|:----:|
| dry-run | `--dry-run` | 패킷 생성 검증 (전송 없음) |
| simulate | `--simulate --tcp HOST:PORT` | 시나리오 시퀀스 전송 |
| live | `--live --tcp HOST:PORT` | 카메라 실시간 E2E |
| loopback | `--loopback --port /dev/ttyUSB0` | TX→RX 하드웨어 검증 |
